Manual Tecnico

1. Estructura del Proyecto

El proyecto esta organizado en una carpeta principal que contiene todos los archivos HTML, el archivo CSS y las subcarpetas necesarias para los recursos.

  1. Carpeta raiz: contiene index.html, menu.html, estilo.css y todas las paginas.
  2. Carpeta imagenes: contiene las 10 imagenes usadas en la galeria.
  3. Carpeta musica: contiene los archivos mp3 que se reproducen en la pagina del juego.
  4. Carpeta quake: contiene el motor WebQuake y los archivos del juego.
  5. Carpeta quake/id1: contiene el archivo pak0.pak con los datos del juego Quake.

2. Creacion del index.html con Frames

El archivo index.html utiliza la etiqueta frameset para dividir la pantalla en dos secciones. La columna izquierda tiene un ancho fijo de 220 pixeles y muestra el menu de navegacion. La columna derecha ocupa el resto del espacio y carga las paginas cuando el usuario hace clic en un enlace.

  1. Se uso la etiqueta frameset con el atributo cols="220px,*" para definir las columnas.
  2. El primer frame carga menu.html y tiene el nombre "menu".
  3. El segundo frame carga bienvenida.html al inicio y tiene el nombre "contenido".
  4. Los enlaces del menu usan target="contenido" para abrir las paginas en el frame derecho.
  5. El enlace del juego usa target="_top" para abrir fuera del frameset.

3. Diseno con CSS

El archivo estilo.css aplica el diseno visual a todas las paginas del sitio. Se utilizo un esquema de colores oscuro con tonos azul y morado. Las propiedades principales utilizadas fueron las siguientes.

  1. background-color: define el color de fondo de cada elemento.
  2. font-family: se uso Arial como fuente principal por ser compatible con todos los navegadores.
  3. border-radius: redondea las esquinas de los botones y las imagenes.
  4. border-left: agrega una linea de color morado al lado izquierdo de cada enlace del menu.
  5. display flex con flex-wrap wrap: permite que las imagenes de la galeria se acomoden automaticamente en filas.
  6. border-collapse collapse: elimina el espacio doble entre celdas de la tabla.
  7. object-fit cover: hace que las imagenes llenen su espacio sin deformarse.

4. Menu de Navegacion

El menu se creo en un archivo separado llamado menu.html. Contiene una lista desordenada con enlaces a cada seccion del sitio. Cada enlace tiene el atributo target que indica en que frame o ventana se abre la pagina.

  1. Se uso la etiqueta ul para crear la lista de enlaces.
  2. Cada enlace tiene href con la ruta del archivo y target con el nombre del frame destino.
  3. El CSS elimina los puntos de la lista con list-style-type none.
  4. Se agrego un borde izquierdo de color morado a cada enlace con border-left.

5. Galeria de Imagenes

La galeria muestra 10 imagenes usando un contenedor div con la clase galeria. El CSS aplica flexbox para acomodar las imagenes en filas automaticamente segun el ancho disponible.

  1. Se creo una carpeta llamada imagenes dentro del proyecto.
  2. Las imagenes se nombraron img1.jpg hasta img10.jpg.
  3. Se uso display flex y flex-wrap wrap para el contenedor.
  4. Cada imagen tiene width 200px, height 140px y object-fit cover.
  5. Se agrego border-radius para redondear las esquinas.

6. Video de YouTube

El video se inserto usando la etiqueta iframe apuntando a la URL de embed de YouTube. Esta URL tiene el formato youtube.com/embed/ seguido del ID del video.

  1. Se copio el ID del video desde la URL de YouTube.
  2. Se construyo la URL de embed con el formato correcto.
  3. Se agrego el atributo allowfullscreen para permitir pantalla completa.
  4. El video solo funciona cuando la pagina esta publicada en un dominio real como GitHub Pages.

7. Tabla de Notas

La tabla de notas se creo con las etiquetas table, tr, th y td. Se agrego una columna extra para mostrar el promedio de cada curso calculado manualmente.

  1. Se uso th para los encabezados con fondo morado definido en el CSS.
  2. Se uso td para cada celda de datos con padding de 10px.
  3. border-collapse collapse elimina el espacio entre celdas.
  4. Se agrego border-bottom a cada fila para separar visualmente los datos.

8. Juego Quake

Se integro el juego Quake 1 usando WebQuake, un port del motor original a JavaScript. Los archivos del juego se alojan dentro del propio repositorio para que funcionen sin depender de servidores externos.

  1. Se descargo WebQuake desde GitHub y se copio la carpeta Client/WebQuake al proyecto.
  2. Se descargo el archivo pak0.pak del shareware de Quake 1 y se coloco en quake/id1/.
  3. Se creo un archivo autoexec.cfg en quake/id1/ para configurar los controles WASD y el mouse.
  4. Se modifico el archivo IN.js para que el mouse quede capturado con un solo clic.
  5. El enlace del menu usa target="_top" para abrir la pagina fuera del frameset.
  6. El boton de jugar usa target="_blank" para abrir el juego en una pestaña nueva.
  7. Los archivos en quake/id1/ se nombraron en minusculas para compatibilidad con GitHub Pages.

9. Musica de Fondo

La pagina del juego incluye un reproductor de musica usando la etiqueta audio de HTML5. Las canciones se almacenan en una carpeta llamada musica dentro del proyecto.

  1. Se creo una carpeta musica y se colocaron los archivos mp3 dentro.
  2. Se uso la etiqueta audio con JavaScript para crear una lista de reproduccion.
  3. Las canciones se reproducen en orden y vuelven al inicio al terminar la ultima.
  4. Se agrego un control visual fijo en la esquina inferior derecha de la pagina.

10. Publicacion en GitHub Pages

  1. Se creo un repositorio en github.com.
  2. Se subieron todos los archivos del proyecto al repositorio.
  3. En Settings, seccion Pages, se selecciono la rama main como fuente.
  4. GitHub genera automaticamente una URL publica para acceder al sitio.
  5. Se verifico que todos los enlaces, el video y el juego funcionaran correctamente.
