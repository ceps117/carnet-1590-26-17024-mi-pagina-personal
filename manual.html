Manual Tecnico

1. Estructura del Proyecto

El proyecto esta organizado en una carpeta principal con todos los archivos HTML, el CSS y subcarpetas para recursos. Esta estructura es importante para que los enlaces entre archivos funcionen correctamente.

  1. Carpeta raiz: index.html, menu.html, estilo.css y todas las paginas HTML.
  2. Carpeta imagenes: las 10 imagenes de la galeria y la foto de perfil.
  3. Carpeta musica: archivos mp3 del reproductor de la pagina del juego.
  4. Carpeta quake: motor WebQuake y archivos del juego Quake.
  5. Carpeta quake/id1: archivo pak0.pak con los datos del juego.

2. Creacion del index.html con Frames

El archivo index.html usa frameset para dividir la pantalla en dos columnas. La izquierda tiene 220px fijos y muestra el menu. La derecha ocupa el resto y carga las paginas al hacer clic en los enlaces del menu.

  1. Se uso frameset con cols="220px,*" para las dos columnas.
  2. El primer frame carga menu.html con el nombre "menu".
  3. El segundo frame carga bienvenida.html con el nombre "contenido".
  4. Los enlaces del menu usan target="contenido" para abrir en el frame derecho.
  5. El enlace del juego usa target="_top" para salir del frameset completamente.

3. Diseno con CSS

El archivo estilo.css aplica el diseno visual a todas las paginas. Se uso un esquema oscuro con azul y morado. No se usaron frameworks externos, todo es CSS puro con propiedades basicas accesibles para cualquier nivel.

  1. background-color define el color de fondo de cada elemento.
  2. font-family Arial se uso por compatibilidad con todos los navegadores.
  3. border-radius redondea las esquinas de botones e imagenes.
  4. border-left agrega una linea morada al lado izquierdo de cada enlace.
  5. display flex con flex-wrap wrap acomoda las imagenes en filas automaticamente.
  6. border-collapse collapse elimina el espacio doble entre celdas de la tabla.
  7. object-fit cover hace que las imagenes llenen su espacio sin deformarse.

4. Menu de Navegacion

El menu esta en menu.html usando una lista desordenada ul con enlaces a cada seccion. Cada enlace tiene el atributo target para indicar donde se abre la pagina. Se agrego un boton de inicio para volver a bienvenida.html.

  1. Se uso ul y li para crear la lista de enlaces.
  2. Cada a tiene href con la ruta del archivo y target con el destino.
  3. El CSS elimina los puntos de la lista con list-style-type none.
  4. El boton de inicio usa target="contenido" para cargar bienvenida.html en el frame derecho.
  5. Se uso border-left para dar el efecto visual de barra lateral en cada enlace.

5. Galeria de Imagenes con Lightbox

La galeria muestra 10 imagenes con flexbox. Al hacer clic en una se abre en grande con un efecto lightbox hecho en JavaScript puro sin librerias externas. Se cierra con el boton X, haciendo clic fuera de la imagen, o presionando ESC.

  1. Se creo la carpeta imagenes con los archivos img1.jpg hasta img10.jpg.
  2. Se uso display flex y flex-wrap wrap en el contenedor de la galeria.
  3. El lightbox es un div con position fixed que cubre toda la pantalla con fondo oscuro.
  4. Al hacer clic en una imagen, JavaScript copia su src al img del lightbox y lo muestra.
  5. Un listener de teclado permite cerrar el lightbox con la tecla ESC.
  6. El boton X en la esquina superior derecha tambien cierra el lightbox.

6. Video de YouTube

El video se inserto con la etiqueta iframe apuntando a la URL de embed de YouTube. El formato es youtube.com/embed/ seguido del ID del video. Solo funciona en un dominio real como GitHub Pages, no al abrir el archivo local.

  1. Se copio el ID del video desde la URL de YouTube.
  2. Se construyo la URL de embed con el formato correcto.
  3. Se agrego allowfullscreen para permitir pantalla completa.
  4. Para playlists se usa el formato youtube.com/embed/videoseries?list=ID.

7. Tabla de Notas

La tabla se creo con las etiquetas table, tr, th y td. Se agrego una columna extra de promedio calculada manualmente. El CSS aplica fondo oscuro con encabezados morados y separa las filas con border-bottom.

  1. Se uso th para los encabezados con fondo morado definido en el CSS.
  2. Se uso td para cada celda con padding de 10px.
  3. border-collapse collapse elimina el espacio doble entre celdas.
  4. border-bottom en cada td separa visualmente las filas.

8. Reproductor de Musica

La pagina del juego tiene un reproductor usando la etiqueta audio de HTML5 y JavaScript. Las canciones estan en la carpeta musica y se reproducen en orden volviendo al inicio al terminar la ultima.

  1. Se creo la carpeta musica con cancion1.mp3 hasta cancion5.mp3.
  2. Se uso la etiqueta audio con autoplay para iniciar al cargar la pagina.
  3. JavaScript maneja un arreglo de canciones y un indice para saber cual esta activa.
  4. El evento ended llama automaticamente a siguiente() al terminar cada cancion.
  5. El reproductor visual es un div con position fixed en la esquina inferior derecha.
  6. Los botones de anterior, pausa y siguiente cambian el src del audio y llaman a play().

9. Juego Quake

Se integro Quake 1 usando WebQuake, un port del motor original a JavaScript. Los archivos se alojan en el repositorio para no depender de servidores externos. Se modifico IN.js para mejorar el control del mouse y se creo autoexec.cfg para configurar los controles al inicio.

  1. Se descargo WebQuake desde GitHub y se copio Client/WebQuake al proyecto.
  2. Se descargo el shareware pak0.pak y se coloco en quake/id1/ en minusculas.
  3. Se creo autoexec.cfg en quake/id1/ para configurar WASD, mouse y freelook.
  4. Se modifico IN.js para capturar el mouse con un solo clic y activar freelook completo.
  5. El enlace del menu usa target="_top" para salir del frameset.
  6. El boton jugar usa target="_blank" para abrir en pestana nueva donde los controles funcionan.
  7. Los archivos en quake/id1/ se nombraron en minusculas para compatibilidad con Linux y GitHub Pages.

10. Publicacion en GitHub Pages

El sitio se publico en GitHub Pages de forma gratuita. Esto genera una URL publica donde todo funciona correctamente incluyendo el video de YouTube y el juego Quake con sus archivos locales.

  1. Se creo un repositorio en github.com.
  2. Se subieron todos los archivos del proyecto incluyendo la carpeta quake completa.
  3. En Settings, seccion Pages, se selecciono la rama main como fuente.
  4. GitHub genera automaticamente la URL usuario.github.io/nombre-repositorio.
  5. Se verifico que todos los enlaces, el video y el juego funcionaran correctamente.
